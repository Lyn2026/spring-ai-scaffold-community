# 售后政策（示例文档）

## 退换货时效

- 签收后 **7 天内**可申请无理由退货，商品需保持吊牌完整、未使用。
- 签收后 **15 天内**出现质量问题可申请换货，运费由商家承担。
- 定制类、贴身类商品不支持无理由退货，质量问题除外。

## 退款到账时间

| 支付方式 | 退款到账 |
| --- | --- |
| 支付宝 | 1～3 个工作日 |
| 微信支付 | 1～3 个工作日 |
| 银行卡 | 3～7 个工作日 |

退款原路返回，不支持退到其他账户。

## 运费规则

- 无理由退货：往返运费由买家承担。
- 质量问题：往返运费由商家承担，凭快递单报销。
- 单笔订单满 99 元包邮，偏远地区除外。

## 发票

- 支持开具电子普通发票，下单时勾选或收货后 30 天内申请。
- 增值税专用发票需提供一般纳税人资质，5 个工作日内开出。

## 客服工作时间

工作日 9:00–18:00，法定节假日 10:00–16:00。紧急问题可在对话中留言，次日优先处理。
